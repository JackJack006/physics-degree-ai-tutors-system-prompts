# ⚛️ Physics Degree AI Tutors (System Prompts)

Raccolta di **System Prompts** (progettati per i **Gem di Gemini**, GPT personalizzati o altri LLM) per simulare tutor universitari rigorosi nelle materie del corso di laurea in Fisica.

L'obiettivo di questi prompt non è fornire soluzioni pronte o risposte rapide, ma agire come veri e propri docenti/tutor che utilizzano il **metodo socratico**, incoraggiano il rigore formale, correggono gli errori concettuali ed evidenziano controesempi.

---

## 🚀 Come utilizzare i Prompt

Questi file contengono **Istruzioni di Sistema** e non singole domande.

1. Seleziona la materia di tuo interesse dalla lista qui sotto o sfoglia le cartelle del repository.
2. Apri il file `.md` corrispondente e copia l'intero testo del prompt.
3. Apri la tua piattaforma AI preferita (es. **Gemini** $\rightarrow$ *Crea un Gem*, oppure **ChatGPT** $\rightarrow$ *Crea un GPT*).
4. Incolla il testo copiato nella sezione **"Istruzioni"**.
5. Salva l'assistente e inizia a interagire chiedendo spiegazioni, dimostrazioni o revisioni di esercizi.
